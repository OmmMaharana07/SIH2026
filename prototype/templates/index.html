SatQuery AI

Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis

Smart India Hackathon 2026 ISRO / Department of Space Computer Vision Multimodal VLM Remote Sensing
🎯

Problem Statement

Develop an interactive AI assistant that allows non-expert users and analysts to query high-volume satellite imagery through conversational natural language, extracting accurate, grounded geospatial insights without complex GIS tool friction.

⚙️

Multimodal Architecture

Integrates 5 specialized perception & reasoning layers: Presentation Layer, Agentic Query Router, Multispectral Perception Engine (NDVI, NDWI, CIR), Visual Grounding Bounding Box Localizer, and Grounded Vision-Language Synthesis.

🔄

Bi-Temporal & SAR Intelligence

Features bi-temporal pixel differential tracking to quantify environmental changes over time, as well as Synthetic Aperture Radar (SAR) cross-modal fusion to penetrate cloud cover and map structural roughness.

🌍

Dataset & Spectral Standards

Calibrated against benchmark satellite datasets across 4 core biomes (Cloudy, Desert, Green Forests, Water Bodies) with mathematical parity to Sentinel-2 MSI and Landsat-9 radiometric channels.

Technology Stack & Design Principles

🐍 Python Flask REST API
🖼️ Pillow + NumPy Spectral Pipeline
✨ Vanilla CSS3 Design System
⚡ Modern ES6+ Web Framework
🤖 Gemini 1.5 Vision / Rule Engine
🎤 Web Speech Audio Synthesis
